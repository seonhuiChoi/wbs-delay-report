## 1. 목적

근로기준법 및 사내 인사규정이 정한 근로시간 제약을 **기계가 판정 가능한 형태**로 정의한다.
본 문서의 규칙은 두 곳에서 사용된다.

| 사용처 | 용도 |
|---|---|
| `DS-015` AI 스케줄 자동편성 엔진 | 배정 최적화의 **하드 제약** — 위반 해는 실행 가능해에서 제외 |
| 근태 규칙 엔진 (운영) | 실적 기준 **사후 위반 감지** 및 알림 |

> **설계 원칙** — 사전(편성)과 사후(실적)에 **동일한 규칙 정의를 사용**한다.
> 두 곳의 판정 로직이 갈라지면 "편성은 합법인데 실적은 위반"이 발생하고, 이는 시스템 신뢰를 즉시 무너뜨린다.

## 3. 하드 제약 정의 (12종)

각 제약은 `DS-015` §4.2의 동일 ID로 구현된다.

### HC-01 · 주 근로시간 상한

| 항목 | 내용 |
|---|---|
| 근거 | 근기법 §50, §53 |
| 규칙 | 1주 소정근로 + 연장근로 ≤ **52시간** |
| 판정식 | `Σ_{t ∈ week(w)} ( h[e][t] + ot[e][t] ) ≤ 52` |
| 주 기산 | 월요일 00:00 ~ 일요일 24:00 |
| 탄력근로 적용 시 | 단위기간 평균 40시간 이내, 특정 주 최대 **52시간**, 특정일 최대 12시간 |
| **미확정** | 단위기간 3개월(§51) / 6개월(§51의2) — 6개월 적용 시 근로자대표 서면합의 및 임금보전방안 필요 |
| 위반 시 | 편성 단계 = 해 제외 · 실적 단계 = 즉시 알림 (법 위반) |

### HC-02 · 1일 근로시간 상한

| 항목 | 내용 |
|---|---|
| 근거 | 근기법 §50, §53 |
| 규칙 | 1일 소정 + 연장 ≤ **12시간** |
| 판정식 | `h[e][t] + ot[e][t] ≤ 12` |
| 비고 | 소정 8h 초과분은 연장근로로 분류되며 `HC-01` 주 한도에 합산 |

### HC-03 · 근무 간 최소 휴식

| 항목 | 내용 |
|---|---|
| 근거 | 인사규정 §22 (법정 의무 아님, 협약상 의무) |
| 규칙 | 전일 근무 종료 ~ 익일 근무 시작 **≥ 11시간** |
| 판정식 | `start[e][t+1] − end[e][t] ≥ 11h` |
| 대표 충돌 | `WT-03`(마감 23:00 종료) 다음날 `WT-01`(오픈 08:00) = **9시간** → **배정 불가** |
| | `WT-04`(심야 07:00 종료) 다음날 `WT-12`(09:00) = 26시간 → 가능 |
| 예외 | 재해·긴급 복구 시 점포장 승인으로 1회 예외, 사후 인사팀 보고 |

### HC-04 · 휴게시간

| 항목 | 내용 |
|---|---|
| 근거 | 근기법 §54 |
| 규칙 | 근로 4시간마다 30분 이상, 8시간마다 60분 이상 |
| 구현 | **근무유형 정의에 내재** (`DS-014` §2) — 별도 판정 불필요 |
| 예외 처리 | `WT-14`(교육·행사) 가변 근무만 실적 기준 사후 판정 |
| 관련 CR | `CR-2026-007` — 휴게시간 **자동 분할 기록 및 근로자 확인** 절차 추가 (승인 2026-09-18) |

### HC-05 · 주휴일 보장

| 항목 | 내용 |
|---|---|
| 근거 | 근기법 §55 |
| 규칙 | 1주 소정근로일 개근 시 1일 이상 유급휴일 |
| 판정식 | `Σ_{t ∈ week(w)} x[e][t][WT-00] ≥ 1` |
| 비고 | 단시간 근로자는 소정근로시간 비례 주휴수당 산정 (`DS-021` 연계) |

## 4. 근로시간 산정 규칙

### 4.1 시간 분류

| 분류 | 정의 | 가산 |
|---|---|---|
| 소정근로 | 근무유형에 정의된 근로시간 (휴게 제외) | — |
| 연장근로 | 1일 8h 초과 또는 1주 40h 초과 | 50% |
| 야간근로 | 22:00 ~ 06:00 사이 근로 | 50% |
| 휴일근로 | 주휴일·약정휴일 근로 | 8h 이내 50% / 초과분 100% |

### 4.2 중복 산정 순서

```
① 실근로시간 확정        (실적 기준, 휴게 제외)
      ↓
② 휴일 여부 판정          주휴일·약정휴일 → 휴일근로로 분류
      ↓
③ 연장근로 산정          일 8h 초과분 + 주 40h 초과분 (중복 제외)
      ↓
④ 야간근로 산정          22:00~06:00 겹치는 구간 (①~③과 독립적으로 별도 가산)
      ↓
⑤ 가산 합산              각 가산을 합산 (중복 가산 허용)
```

**예시 — 휴일 야간 10시간 근무 (`WT-09` + 연장 2h)**

| 구성 | 시간 | 가산율 | 계산 |
|---|---|---|---|
| 휴일근로 8h 이내 | 8.0h | 50% | 통상시급 × 8 × 1.5 |
| 휴일근로 8h 초과 | 2.0h | 100% | 통상시급 × 2 × 2.0 |
| 야간근로 (22–23시) | 1.0h | 50% | 통상시급 × 1 × 0.5 **추가** |

> 이 산정 순서는 `DS-014` §2.1 및 `DS-021` §3과 **동일해야 한다.**
> `DS-021` 1차 검토 반려(MT-2026-034) 사유 23건 중 17건이 이 순서 미명시에서 비롯되었다.

### 4.3 의무휴업일 처리

| 항목 | 내용 |
|---|---|
| 근거 | 유통산업발전법 §12의2 · 지자체 조례 |
| 대상 | 대형마트 62개점 (백화점·트레이더스 일부 제외) |
| 주기 | 월 2회 (지자체별 상이 — 둘째·넷째 일요일이 다수) |
| 편성 처리 | 해당 일자는 영업 부문 배정 제외, **재고·시설 부문만 별도 기준으로 배정** |
| 데이터 | 점포별 의무휴업 캘린더 마스터 (연 1회 갱신 + 조례 변경 시) |
