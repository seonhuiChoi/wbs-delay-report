## 1. 목적과 배경

### 1.1 목적
71개 점포가 각자 운영하던 **근무유형 47종을 표준 14종으로 통합**하고,
각 유형의 근로시간·휴게·가산 규칙을 기계가 판정할 수 있는 형태로 정의한다.

### 1.2 표준화가 필요한 이유

| 관점 | 47종 유지 시 | 14종 표준화 시 |
|---|---|---|
| 급여 산정 | 점포별 가산 해석 상이 → 정산 오류 | 단일 규칙 적용 |
| AI 자동편성 | 결정 변수 `|e|×28×48` · 최적화 412초 | `|e|×28×15` · **탐색공간 1/3** |
| 인력 교류 | 점포 간 파견 시 근무유형 재해석 필요 | 코드 그대로 이동 |
| 법정 준수 | 유형별 휴게 규칙 누락 위험 | 유형 정의에 휴게 내재 |

### 1.3 표준화 원칙

1. **소정근로시간은 8.0h 또는 5.0h 두 가지만 둔다.** (전일제 / 단시간)
2. **휴게시간은 근무유형 정의에 포함한다.** 별도 입력·판단 대상이 아니다. (근기법 §54 자동 준수)
3. **점포 유형별 전용 코드는 최소화한다.** 백화점·트레이더스는 영업시간이 구조적으로 달라 불가피한 3종만 유지.
4. **가변 근무는 1종으로 묶고 예외 처리한다.** (`WT-14`)

## 4. 미합의 5종 — 쟁점과 대안

### 4.1 `WT-04` 심야 재고 (22:00 – 07:00)

| 항목 | 내용 |
|---|---|
| 쟁점 | 야간 전담 **고정배치** vs **순환배치** |
| 사측 | 심야 재고 작업은 숙련도 의존이 커 고정 인력 운영이 효율적 |
| 노측 | 야간 고정은 건강권 침해. 순환배치로 부담 분산 요구 |
| AI 영향 | 고정이면 `WT-04` 후보를 특정 사원으로 제한, 순환이면 `SC-02` 형평성 제약으로 처리 — **모델 구조가 달라진다** |
| 대안 A | 순환배치 원칙 + 월 야간 상한 8회 (`HC` 신규 제약 추가) |
| 대안 B | 희망자 고정배치 + 야간수당 외 별도 보전, 미충원분만 순환 |
| **권고** | **대안 A** — `DS-015` `SC-02` 가중치 0.20에 이미 반영되어 있어 추가 개발 없이 수용 가능 |

## 7. 점포별 예외 승인 절차

표준 14종으로 운영이 불가능한 점포는 아래 절차로 예외를 신청한다.

```
점포장 예외 신청  →  본사 인사팀 검토(5영업일)  →  노사협의회 보고  →  승인/반려
                                                        │
                                          승인 시 → 예외 코드 부여 (WT-9x)
                                                     유효기간 6개월 · 갱신 심사
```

예외 코드는 **최대 3종까지만** 운영하며, 초과 시 표준 코드 개정 안건으로 전환한다.
AI 편성 엔진은 예외 코드를 해당 점포에서만 후보로 포함한다.
