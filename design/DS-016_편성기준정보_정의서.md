> 미회신 27개점은 "기준이라 할 만한 것이 원래 없었다" — 그동안 점포장 경험으로 편성해왔기 때문이다.
> 이 기준이 없으면 엔진은 **슬롯마다 몇 명이 필요한지를 모른다.** 배정 계산 자체가 성립하지 않는다.

## 1. 목적

`DS-015` AI 스케줄 자동편성 엔진이 읽어들이는 **기준정보와 신청정보**의 범위·스키마·확보 절차를 정의한다.

> **이 문서는 학습 데이터 정의서가 아니다.**
> 엔진은 과거 실적을 학습하지 않으므로 학습 데이터셋·피처·라벨이 존재하지 않는다.
> 여기서 정의하는 것은 **엔진이 매 편성 시점에 조회하는 입력값**이다.

## 3. `MD-02` 필요인원 기준 — 핵심 미확보 항목

### 3.1 스키마

| 컬럼 | 설명 | 예시 |
|---|---|---|
| `store_cd` | 점포 코드 | `M-0142` |
| `dept_cd` | 부문 코드 | `CHK`(계산) `FRS`(신선) `GRC`(그로서리) `CSD`(고객서비스) |
| `day_type` | 요일유형 | 평일 / 토 / 일 / 공휴일 / 의무휴업 |
| `biz_type` | 영업유형 | 정상 / 연장영업 / 행사기간 / 명절특별 |
| `slot` | 30분 슬롯 | `14:00` `14:30` … |
| `req_staff` | **적정 인원** | 6 |
| `min_staff` | **최소 인원** (안전·운영 하한) | 2 |
| `cert_req` | 필수 자격 인원 | 정육 1 |
| `valid_from` / `valid_to` | 적용 기간 | |
| `confirmed_by` / `confirmed_dt` | 확정자 · 확정일 | 점포운영팀 |

### 3.2 규모

```
71개점 × 평균 6부문 × 5요일유형 × 4영업유형 × 평균 26슬롯  ≈  221,000행
```

전건을 사람이 입력할 수는 없으므로 **템플릿 + 일괄 등록** 방식으로 수집한다.
점포는 대표 패턴(평일/토/일 × 정상)만 입력하고, 나머지는 배수 규칙으로 자동 확장한다.

### 3.3 수집 현황 (2026-10-08)

| 점포 유형 | 대상 | 확정 | 회신률 |
|---|---|---|---|
| 대형마트 | 62 | 39 | 62.9% |
| 백화점 | 9 | 5 | 55.6% |
| **합계** | **71** | **44** | **62.0%** |

### 3.4 미회신 27개점 사유 분석

| 사유 | 점포 수 | 성격 |
|---|---|---|
| **기준 자체가 존재하지 않음** — 점포장 경험으로 편성해옴 | 16 | 신규 수립 필요 |
| 부문 구분이 본사 표준과 달라 매핑 불가 | 6 | 표준 매핑 필요 |
| 담당자 부재 / 우선순위 미부여 | 5 | 독촉으로 해결 |

> **이것이 지연의 실체다.** 회신을 안 해준 것이 아니라 **회신할 내용이 없었다.**
> 그동안 "토요일 오후에 몇 명이 필요한가"는 점포장 머릿속에만 있었고 문서화된 적이 없다.
> 따라서 독촉은 효과가 없으며, **기준을 함께 만들어주는 방식**이어야 한다. (§5.2)

### 3.5 임시값 처리

기준 미확정 점포는 아래 순서로 임시값을 적용하고, 화면에 **임시값 배지**를 표시한다.

```
① 동일 점포 · 동일 부문 · 같은 요일유형 기준이 있으면 그것을 사용
② 없으면 동일 점포유형 · 유사 규모(±20% 면적) 점포의 기준을 차용
③ 그것도 없으면 부문 표준 기준표 적용
   → 임시값 비율이 30%를 넘으면 자동 편성을 중단하고 수동 편성 화면 개방 (DS-015 §8.3)
```

## 4. `MD-03` 근태 신청 정보

엔진은 **승인된 신청을 배정 불가 구간으로** 처리하고(HC-10), 희망 신청은 목적함수(SC-03)에 반영한다.

| 신청 유형 | 코드 | 처리 | 승인 |
|---|---|---|---|
| 연차 (종일) | `LV-01` | 해당일 `WT-00` 고정 | 점포장 |
| 반차 (오전/오후) | `LV-02` | 해당 반일 배정 불가 → 단시간 유형만 가능 | 점포장 |
| 경조 휴가 | `LV-03` | 해당 기간 `WT-00` 고정 | 인사팀 |
| 병가 | `LV-04` | 해당 기간 `WT-00` 고정 | 인사팀 |
| 공가 (예비군·건강검진) | `LV-05` | 해당일 `WT-00` 고정 | 점포장 |
| 교육 · 파견 | `TR-01` | `WT-14`(교육) 고정 배정 | 인사팀 |
| **희망 근무** | `PF-01` | SC-03 가점 (강제 아님) | 승인 불요 |
| **희망 비번** | `PF-02` | SC-03 가점 (강제 아님) | 승인 불요 |

### 4.1 신청 마감 규칙

| 항목 | 기준 |
|---|---|
| 편성 대상 기간 | 근무 개시 4주 전 ~ 2주 전 |
| 연차·교육 신청 마감 | 편성 실행 **3일 전** |
| 희망 근무/비번 마감 | 편성 실행 **3일 전** |
| 마감 후 신청 | 확정 스케줄에 대한 **변경 요청**으로 처리 → 점포장 조정 + 부분 재최적화 |

> **희망 신청은 강제가 아니다.** SC-03 가중치 0.18로 반영되며, 법정 제약이나 필요인원과 충돌하면 반영되지 않는다.
> 반영되지 않은 경우 그 사유를 배정 근거에 표시한다. (`DS-015` §6)

### 4.2 현재 상태

모바일 희망 신청 화면(`4.2.3`)이 CR-2026-007 반영으로 지연되어 **희망 신청 채널이 아직 열리지 않았다.**
그 결과 1차 시뮬레이션의 희망 반영률 58%는 **신청 건수 자체가 적어서** 나온 값이며, 엔진 성능을 나타내지 않는다.
(`DS-015` §9.3)

|---|---|
| 집계 대상 | 사원별 **야간 배정 횟수**, **휴일 배정 횟수** (별도 집계) |
