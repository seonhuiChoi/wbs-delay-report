| 계획완료일 | 2026-10-02 |
| 검토상태 | **보완필요** — 1차 검토 **반려** (MT-2026-034) · 의견 23건 중 미조치 9건 |
| 연관 WBS_ID | `4.5.2` |

> **1차 반려 사유** — 검토의견 23건 중 **17건(74%)이 수당 산정 규칙 미준수**였다.
> 근본 원인은 본 설계서의 오류가 아니라, **선행 산출물(`DS-006` `DS-014`)에 가산 중복 적용 순서가 명시되지 않은 상태**에서
> 작성이 진행된 데 있다. 두 문서에 순서가 명문화된 뒤(각 v0.9 / v0.7) 본 문서를 재작성 중이다.

---

## 1. 목적과 범위

신규 자동 스케줄 관리 시스템의 근태 실적을 **기존 급여 시스템으로 무결하게 전달**하고,
전환 시점의 데이터 정합성을 보장한다.

| 구분 | 범위 |
|---|---|
| 이관 대상 | 근태 실적 24개월 · 근무유형 마스터 · 개인 계약 정보 |
| 연계 대상 | 월 급여 마감 배치 (매월 1일 ~ 3일) |
| 검증 방식 | **2개월 병행운영** — 신규/기존 산출 결과 대사 |
| 범위 외 | 급여 계산 로직 자체 (기존 급여 시스템 유지) · 4대보험 · 연말정산 |

## 2. 이관 설계

### 2.1 이관 대상 데이터

| # | 대상 | 원천 | 건수(추정) | 이관 방식 | 비고 |
|---|---|---|---|---|---|
| 1 | 근태 실적 이력 | `ATT.TB_WORK_RECORD` | 약 6,800만 | 일괄 + 코드 변환 | 근무유형 47→14 매핑 |
| 2 | 근무유형 마스터 | 점포별 개별 관리 | 47 → **14** | 신규 정의 후 매핑 테이블 보관 | `DS-014` §3 |
| 3 | 개인 계약 정보 | `HR.TB_CONTRACT` | 11,500 | 일괄 | 단시간 계약시간 포함 |
| 4 | 미지급 정산 잔액 | 급여 시스템 | 약 3,200 | **수작업 대사 후 이관** | 전환 시점 잔액 |
| 5 | 연차 부여·사용 이력 | `ATT.TB_ANNUAL` | 약 42만 | 일괄 | 잔여 연차 검증 필수 |

### 2.2 근무유형 코드 변환

과거 24개월 근태 실적의 근무유형은 현행 47종이므로, `DS-014` §3 매핑 테이블로 **소급 변환**한다.

```
변환 규칙
  ① DS-014 §3 매핑 테이블 적용                      (47 → 14)
  ② 변환 후 소정근로시간이 원본과 다른 경우
       → 원본 실적 시각(actual_in/out)을 우선하고
         근무유형은 참조 값으로만 보관               (실적 불변 원칙)
  ③ 매핑 불가 건 (예외 코드·오입력)
       → WT-99(미분류)로 적재 후 별도 리스트 통보
```

> **실적 불변 원칙** — 소급 변환은 **분류 라벨만 바꾸며 실근로시간·지급 실적을 변경하지 않는다.**
> 과거 급여는 이미 지급·정산이 완료되었으므로 어떤 경우에도 재산정하지 않는다.

**변환 시뮬레이션 결과 (6개월 샘플 1,690만 건 기준)**

| 결과 | 건수 | 비율 |
|---|---|---|
| 1:1 정상 변환 | 15,912,400 | 94.2% |
| 시각 조정 동반 변환 (라벨만) | 901,300 | 5.3% |
| `WT-99` 미분류 | 76,300 | 0.5% |

미분류 76,300건은 대부분 폐점·통합된 점포의 구 코드다. 이관 후 별도 아카이브 테이블로 분리한다.

## 3. 수당 산정 규칙 반영

> 아래 순서는 `DS-006` §4.2 및 `DS-014` §2.1과 **동일해야 한다.** 1차 반려의 핵심 지적 사항이다.

### 3.1 산정 순서

```
① 실근로시간 확정      실적 기준 (휴게 제외)
      ↓
② 휴일 여부 판정        주휴일 · 약정휴일 → 휴일근로로 분류
      ↓
③ 연장근로 산정        일 8h 초과분 + 주 40h 초과분 (중복 제외)
      ↓
④ 야간근로 산정        22:00~06:00 겹치는 구간 (①~③과 독립 · 별도 가산)
      ↓
⑤ 가산 합산            각 가산 합산 (중복 가산 허용)
```

### 3.2 가산율

| 구분 | 가산율 | 근거 |
|---|---|---|
| 연장근로 | 50% | 근기법 §56① |
| 야간근로 | 50% | 근기법 §56③ |
| 휴일근로 8h 이내 | 50% | 근기법 §56② |
| 휴일근로 8h 초과 | 100% | 근기법 §56② |

### 3.3 검증 케이스

| # | 근무 상황 | 근무유형 | 실근로 | 기대 산정 |
|---|---|---|---|---|
| C-01 | 평일 정상 | `WT-01` | 8.0h | 소정 8h · 가산 없음 |
| C-02 | 평일 마감 | `WT-03` | 8.0h | 소정 8h + 야간 1h(50%) |
| C-03 | 평일 심야 | `WT-04` | 8.0h | 소정 8h + 야간 8h(50%) |
| C-04 | 평일 연장 2h | `WT-01`+OT | 10.0h | 소정 8h + 연장 2h(50%) |
| C-05 | 평일 마감 + 연장 2h | `WT-03`+OT | 10.0h | 소정 8h + 연장 2h(50%) + 야간 3h(50%) |
| C-06 | 휴일 정상 | `WT-08` | 8.0h | 휴일 8h(50%) |
| C-07 | 휴일 마감 | `WT-09` | 8.0h | 휴일 8h(50%) + 야간 1h(50%) |
| C-08 | **휴일 마감 + 연장 2h** | `WT-09`+OT | 10.0h | 휴일 8h(50%) + 휴일초과 2h(100%) + 야간 3h(50%) |
| C-09 | 단시간 정상 | `WT-05` | 5.0h | 소정 5h · 가산 없음 |
| C-10 | 단시간 마감 | `WT-07` | 5.0h | 소정 5h + 야간 1h(50%) |
| C-11 | 단시간 계약 초과 1h | `WT-05`+1h | 6.0h | 소정 5h + 초과 1h(50%, 본인 동의 확인) |
| C-12 | 주휴수당 (단시간) | — | 주 25h | 소정시간 비례 주휴 산정 |

> **C-08이 1차 반려의 대표 지적 사례**다. 초안은 휴일 8h 초과분에 100%가 아닌 50%를 적용하고 야간 가산을 누락했다.

## 4. 정합성 검증 설계

### 4.1 병행운영 (WBS `6.2`)

| 항목 | 내용 |
|---|---|
| 기간 | 2개월분 급여 (2026-10월분 · 11월분) |
| 방식 | 신규 시스템 산출값 ↔ 기존 급여 시스템 산출값 **전건 대사** |
| 대상 | 직영 8,400명 전원 |
| 판정 | 개인별 총 지급액 **차이 0원** |
| 허용 예외 | 없음 — 1원이라도 차이 시 원인 규명 후 재검증 |

> **일정 리스크** — 병행운영은 실제 급여 마감 주기에 종속되므로 **압축이 불가능하다.**
> 10월분(12-01~03 마감)과 11월분(12-22~03 마감) 두 차례가 필요하나,
> 오픈이 12-04이면 11월분 검증은 **오픈 이후**가 된다. (`ISS-016` · `RSK-011`)

### 4.2 대사 항목

| 구분 | 항목 | 허용 오차 |
|---|---|---|
| 근로시간 | 소정 / 연장 / 야간 / 휴일 시간 | 0분 |
| 금액 | 기본급 / 각 가산수당 / 주휴수당 | 0원 |
| 공제 | 지각·조퇴·결근 공제 | 0원 |
| 연차 | 발생 / 사용 / 잔여 일수 | 0일 |

### 4.3 자동 대사 배치

```
매월 마감 D+1  02:00
   ① 신규 시스템 근태 집계 추출
   ② 기존 급여 시스템 산출 결과 수신
   ③ 사원 단위 항목별 대사
   ④ 차이 발생 건 → 원인 코드 분류 → 리포트
        · DIFF-01  근무유형 매핑 차이
        · DIFF-02  가산 산정 순서 차이
        · DIFF-03  휴게시간 처리 차이
        · DIFF-04  단시간 계약시간 해석 차이
        · DIFF-09  기타 (수동 확인)
```
